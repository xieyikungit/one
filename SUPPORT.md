# 有迹支持 / Youji Support

有迹目前是 iPhone 应用。使用问题或功能反馈可在 [GitHub Issues](https://github.com/xieyikungit/one/issues) 提交。请勿在公开反馈中附上含有真实姓名、健康、财务或家庭信息的备份文件。

常见问题：

- **如何备份？** 在「我的人生 → 数据」导出 JSON。备份包含手动记录、目标和档案，不包含 Apple 健康步数。
- **如何恢复？** 在同一位置导入 JSON，先预览，再选择合并或替换。导入前应用会保留最多五份本机快照；当前设备已有的健康步数不会被导入文件覆盖。
- **步数没有出现？** 在 iPhone 的 Apple 健康中检查步数数据和有迹的读取权限，然后回到运动模块手动同步。健康步数需要重新授权读取，不会从 JSON 备份恢复。
- **如何删除数据？** 打开「我的人生 → 数据 → 隐私与数据控制 → 清除本机所有数据」。已导出到其他位置的文件需自行删除。

## English

Youji is currently an iPhone app. For support or feedback, open a [GitHub Issue](https://github.com/xieyikungit/one/issues). Do not attach backups containing real names, health, financial, or family details to a public issue.

- **Back up:** Export JSON from Profile → Data. It contains manual records, goals, and your profile, but not Apple Health steps.
- **Restore:** Import JSON from the same screen, review the preview, then choose merge or replace. The app keeps up to five local pre-import snapshots and preserves Apple Health steps already cached on this device.
- **Missing steps:** Check step data and Youji's read access in Apple Health on an iPhone, then sync again from Exercise. Steps are not restored from JSON backups.
- **Delete data:** Open Profile → Data → Privacy and data controls → Delete all local data. Delete files exported elsewhere separately.
